# webos-adblock - Lista Leve (lite)
# Finalidade: bloquear anuncios, ACR (reconhecimento automatico de conteudo) e telemetria da LG webOS.
# Formato: "0.0.0.0 dominio", um por linha, fins de linha LF. Linhas iniciadas por # sao comentarios.
# /etc/hosts nao aceita curingas; por isso os hosts regionais sao listados um a um.
#
# Fora desta lista de proposito (necessarios para loja, login LG, updates de apps e streaming):
#   lgappstv.com (raiz; so ad.lgappstv.com e bloqueado), lgtvsdp.com (raiz; so rdx2.* e bloqueado),
#   lge.com, lgeapi.com, snu.lge.com, su.lge.com, su-ssl.lge.com e ngfts.lge.com (miniaturas da Content Store).
#
# Fontes consultadas (usadas para conferir nomes de host; a selecao e propria):
#   - hagezi/dns-blocklists, lista "LG webOS Tracker" (native.lgwebos) - https://github.com/hagezi/dns-blocklists
#   - Perflyst/PiHoleBlocklist, SmartTV.txt e regex.list - https://github.com/Perflyst/PiHoleBlocklist
#   - hugobatista/lg-tv-ad-block, camada base "list" - https://github.com/hugobatista/lg-tv-ad-block
# Revisada em 2026-10-13.
