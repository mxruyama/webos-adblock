AdBlocker para webOS

Bloqueia anúncios, telemetria da LG e rastreadores em toda a TV via /etc/hosts (requer root).

URL do repositório do Homebrew Channel:

https://cdn.jsdelivr.net/gh/mxruyama/webos-adblock@gh-pages/repo.json

Alternativa (TVs mais novas): https://mxruyama.github.io/webos-adblock/repo.json. A URL do jsDelivr funciona também em TVs antigas, que não confiam no certificado do GitHub Pages.

Como instalar

  1. Abra o Homebrew Channel na TV.
  2. Abra as configurações: Settings (ícone de engrenagem). A interface do Homebrew Channel é em inglês.
  3. Na seção Repositories, escolha Add repository.
  4. No diálogo Enter repository URL:, digite a URL acima e confirme no botão Add repository.
  5. Volte à lista de aplicativos, abra o AdBlocker e instale.

Versão 1.1.1. Requer TV com acesso root (Homebrew Channel).
